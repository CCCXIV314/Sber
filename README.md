# Sber

## Прогнозирование страховых выплат

Репозиторий содержит решение кейса от СберСтрахования, представленного в финале кейс-чемпионата Cup IT. Задача заключалась в прогнозировании величины страховых выплат.

### 1. Данные

В распоряжении участников находился набор данных с информацией о договорах и оказанных услугах:

 - идентификаторы договоров и документов (service_document_id, другие ID-поля),

 - категории и подкатегории услуг (service_name, service_code),

 - сумма оказанной услуги (service_amount_net),

 - дата и время оказания услуг,

 - информация о сторнировках.

Целевая переменная — величина страховой выплаты.

### 2. Подход к решению

Работа над задачей включала несколько ключевых этапов:

 - Первичное исследование данных (EDA).

 - Feature engineering:

   - обработка категориальных признаков,

   - учёт сторнировок,

   - проверка влияния акций и маркетинговых кампаний на целевую переменную.

 - Подготовка данных для модели.

 - Модель: обучение каскадной модели: SARIMAX для предсказания целевой переменной, CatBoost для предсказания экзогенных переменных, используемых в SARIMAX, настройка гиперпараметров.

 - Анализ важности признаков.

### 3. Результаты

 - Построены и сравнены несколько моделей, наилучшие результаты показала каскадная модель (SARIMAX и CatBoost).

 - Итоговое решение обеспечило качественный прогноз, который может использоваться для практических задач управления рисками в страховой компании.
